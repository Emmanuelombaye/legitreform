# Reform Vital

Physician-guided telehealth for compounded semaglutide and tirzepatide.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm start` | Serve the production build |

## Stack

- Next.js 15 (App Router)
- TypeScript
- React 19

## Note

This is a demonstration site. Checkout is simulated. Completing an intake does not guarantee a prescription. Compounded medications are not FDA-approved.
